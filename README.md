## 💫 About Me
> **"데이터의 정합성을 책임지고, 철저한 검증으로 고가용성 인프라를 설계합니다."**
* 🛡️ **데이터 무결성과 트랜잭션 제어**: 금융 도메인에서의 중복 거래 방지, 데드락 제어 등 데이터의 일관성을 최우선으로 생각합니다.
* 📈 **정량적 성능 개선**: 부하 테스트(k6)와 모니터링(Prometheus/Grafana)을 바탕으로 병목 구간을 추적하고 쿼리 튜닝을 통해 성능을 비약적으로 향상시킵니다.
* 🤝 **주도적인 문제 해결과 협업**: 백엔드 개발에 국한하지 않고, 팀의 원활한 개발을 위해 배포 자동화 및 모니터링 시스템 구축을 주도합니다.

## 🎯 Core Competencies
* **성능 튜닝 & 쿼리 최적화**: MySQL 실행 계획(`EXPLAIN`) 분석 기반의 슬로우 쿼리 진단 및 복합 인덱스 최적화
* **트랜잭션 & 동시성 제어**: 비관적 락(Pessimistic Lock)과 Redis 분산 락을 활용한 데이터 동시성 제어 및 데드락 방지
* **아키텍처 설계 & 공통 처리**: AOP 기반의 공통 멱등성(Idempotency) 검증 구조 설계 및 MVC 필터 레이어 활용 HTTP Request Body 캐싱
* **JPA 최적화**: Fetch Join 활용 N+1 문제 해결 및 벌크 연산 후 영속성 컨텍스트 정합성 관리
* **인프라 리소스 최적화**: Docker 컨테이너 메모리 제한 및 OS 가상 메모리(Swap File) 튜닝을 통한 고가용성 인프라 확보

* **주요 성과**:
  - 병렬 송금 E2E 테스트(20개 요청) 및 동일 멱등성 키 재요청 제어 검증을 통해 자산 데이터 정합성 100% 보장
