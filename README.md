## 🚀 Experience & Capabilities
> 각 스택별 실무 및 프로젝트 적용 경험입니다. (접어서 보기 가능)

<details>
<summary><b>💻 Language & Framework (클릭하여 열기)</b></summary>

* **Java & Kotlin**: Kotlin의 간결한 문법과 Java의 객체지향 패러다임을 이해하고 적재적소에 활용합니다.
* **Spring Boot**: Layered Architecture 기반의 REST API 설계 및 비즈니스 로직을 구축합니다.
* **Spring Data JPA & QueryDSL**: 객체 중심 데이터 접근 방식을 사용하며, 동적 쿼리 및 성능 최적화(N+1 문제 해결 등)에 QueryDSL을 적극 도입합니다.
* **Spring Security & JWT**: 무상태(Stateless) 기반 인증/인가 체계를 구축하고 보안 정책을 적용합니다.
* **JUnit5**: Mockito를 결합하여 비즈니스 레이어의 단위 테스트 및 통합 테스트를 신뢰도 높게 검증합니다.
</details>

<details>
<summary><b>💾 Database & Storage</b></summary>

* **MySQL 8.0**: 테이블 스키마 설계 및 대용량 조인 성능 튜닝이 가능합니다.
* **H2 Database**: 로컬 및 개발 검증 단계에서 인메모리 DB를 사용하여 빠른 테스트를 수행합니다.
* **Redis**: 데이터 캐싱 및 분산 락(Distributed Lock) 활용을 통한 동시성 제어 경험이 있습니다.
* **Flyway**: DB 스키마 형상 관리를 자동화하여 개발-운영 환경 일치율을 유지합니다.
</details>

<details>
<summary><b>☁️ DevOps & Monitoring</b></summary>

* **Docker**: 컨테이너화를 통해 가상 인프라 구축 및 개발 서버 표준화를 주도합니다.
* **AWS EC2**: 리눅스 인스턴스 인프라를 구축하고 외부 접속 포트 및 보안 그룹을 제어합니다.
* **GitHub Actions**: CI/CD 파이프라인을 구축하여 자동 빌드, 테스트 및 원격 배포 자동화를 구현했습니다.
* **Prometheus & Grafana**: 애플리케이션의 핵심 지표(CPU, 메모리, 커넥션 풀 등)를 모니터링하고 시각화 대시보드를 구성합니다.
* **k6**: 가상 유저 시나리오 기반 부하 테스트를 설계하여 시스템 한계점 및 병목 구간을 진단합니다.
</details>
